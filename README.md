# 🛡️ Malicious URL Detector

A Machine Learning-based application designed to identify and classify URLs as either **Legitimate** or **Malicious (Phishing)**. This project helps improve cybersecurity awareness by detecting potentially harmful websites using machine learning techniques.

## 🚀 Features

- Detects malicious and phishing URLs
- Machine Learning-powered classification
- Data preprocessing and feature extraction
- Easy-to-understand workflow
- Built using Python and Scikit-Learn

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Jupyter Notebook

## 📂 Project Structure

```text
├── URL_DETECTOR.ipynb   # Model training and prediction notebook
├── Url_Detector.pkl     # Trained machine learning model
├── README.md
```

## 📊 Dataset

The dataset used for training the model is not included in this repository due to GitHub file size limitations.

## 🎯 Project Goal

The primary objective of this project is to build a machine learning model capable of distinguishing between legitimate and phishing URLs, helping users identify potentially dangerous websites.
